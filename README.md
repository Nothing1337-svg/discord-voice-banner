# Discord Bot

Discord-бот для отслеживания активности пользователей в голосовых каналах сервера.

Бот считает, сколько участников сейчас находится в голосовых и stage-каналах, сохраняет статистику времени в SQLite и генерирует PNG-баннер с текущей активностью. В баннере отображаются количество пользователей в голосе, самый активный участник за выбранный период, его аватар, ник и суммарное время.

## Основные возможности

- отслеживание голосовых каналов в реальном времени;
- подсчет только обычных пользователей, без Discord-ботов;
- сохранение статистики после перезапуска;
- определение самого активного участника за `day`, `week`, `month` или `all`;
- генерация баннера через Pillow;
- slash-команды `/voice_top` и `/voice_banner`;
- конфигурация через `config.toml` и `.env`;
- логирование и обработка ошибок.
